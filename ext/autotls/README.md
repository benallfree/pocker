# autotls

Automatic certificates through ACME: on demand for every served hostname, wildcards through DNS-01, more CAs.

**Runs on:** Single app or multitenant.

> **Planned.** Nothing is published here yet. This folder will hold the plugin's Go module
> (`github.com/pockerbase/pocketbase/ext/autotls`), its tests and a minimal `example/main.go` that builds and shows the
> feature. See [Create your own plugin](../../docs/plugins.md).
