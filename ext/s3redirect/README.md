# s3redirect

File downloads as short-lived signed redirects, after PocketBase's own access check.

**Runs on:** Single app, or many under [pocker](../pocker/README.md).

> **Planned.** Nothing is published here yet. This folder will hold the plugin's Go module
> (`github.com/pockerbase/pocketbase/ext/s3redirect`), its tests and a minimal `example/main.go` that builds and shows the
> feature. See [Create your own plugin](../../docs/plugins.md).
