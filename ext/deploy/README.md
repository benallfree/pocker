# deploy

A deploy API: upload code sets (hooks, migrations, public files), swap them in safely, stream logs. Pluggable auth.

**Runs on:** Single app, or many under [pocker](../pocker/README.md).

> **Planned.** Nothing is published here yet. This folder will hold the plugin's Go module
> (`github.com/pockethost/pocketbase/ext/deploy`), its tests and a minimal `example/main.go` that builds and shows the
> feature. See [Create your own plugin](../../docs/plugins.md).
