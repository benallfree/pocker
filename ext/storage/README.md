# storage

A default storage and backups backend per app (for example an operator bucket) when the app's own S3 is off. Credentials never reach the app.

**Runs on:** Single app, or many under [pocker](../pocker/README.md).

> **Planned.** Nothing is published here yet. This folder will hold the plugin's Go module
> (`github.com/pockerbase/pocketbase/ext/storage`), its tests and a minimal `example/main.go` that builds and shows the
> feature. See [Create your own plugin](../../docs/plugins.md).
