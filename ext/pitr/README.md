# pitr

Point-in-time restore: Litestream replication of each app's database (local or a bucket) and in-place restore from the Backups screen.

**Runs on:** Single app or multitenant.

> **Planned.** Nothing is published here yet. This folder will hold the plugin's Go module
> (`github.com/pockerbase/pocketbase/ext/pitr`), its tests and a minimal `example/main.go` that builds and shows the
> feature. See [Create your own plugin](../../docs/plugins.md).
